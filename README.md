# 🃏 Бар All-in-sect

**3D-онлайн-покер для студентов, где фишки зарабатываются учёбой.**

Проект выполняется в рамках проектной деятельности Института математики, механики и компьютерных наук ЮФУ.

---

## 💡 Идея

**Что создаём.** Многопользовательскую 3D-игру в онлайн-покер. Действие происходит в покерном баре, куда пришли поиграть насекомые с луга: божья коровка, муха, муравей, навозный жук, паук и оса. Заправляет баром богомол: он стоит за стойкой и следит за игрой.

В баре играет спокойная музыка, можно заказать напиток и даже попробовать «смухлевать», пока бармен не видит. Выйти из игры можно почти в любой момент.

**Главная особенность — связь с учёбой.** Каждую неделю игрок получает игровую валюту. Её количество зависит от его результатов в балльно-рейтинговой системе (БРС) за прошлый семестр. Чем лучше учишься, тем больше фишек за столом. Таблица лидеров добавляет соревнования с однокурсниками.

**Для кого.** Для студентов мехмата ЮФУ, которые хотят отдохнуть, посоревноваться друг с другом и получить дополнительный стимул учиться.

## 🎯 Цель и задачи

**Цель:** создать онлайн-покер в атмосфере бара, который превращает учебные успехи студентов в игровую валюту и мотивирует учиться.

**Задачи:**
1. Продумать правила, игровые механики и экономику: как баллы БРС превращаются в фишки.
2. Создать 3D-модели персонажей и интерьера бара в Blender.
3. Реализовать клиент на Unity: игровой стол, раздачи, интерфейс, анимации и звук.
4. Написать сервер и API на C# для сетевой игры.
5. Спроектировать базу данных MySQL: игроки, баланс фишек, баллы, рейтинг.
6. Сделать таблицу лидеров, протестировать и отладить игру.

## 🧩 Структурные части и технологии

Проект состоит из двух основных частей: **клиента** и **сервера**.

```
┌──────────────────────┐        ┌──────────────────────┐        ┌──────────────────┐
│       Клиент         │  API   │        Сервер        │        │   База данных    │
│   Unity · C#         │ ◄────► │   C# · Linux         │ ◄────► │   MySQL          │
│                      │        │                      │        │                  │
│ • 3D-сцена бара      │        │ • комнаты и игроки   │        │ • аккаунты       │
│ • стол, карты, UI    │        │ • логика раздач      │        │ • баланс фишек   │
│ • анимации персонажей│        │ • начисление фишек   │        │ • баллы БРС      │
│ • музыка и звуки     │        │   по БРС             │        │ • таблица лидеров│
└──────────────────────┘        └──────────────────────┘        └──────────────────┘
          ▲
          │ модели
   ┌──────────────┐
   │   Blender    │
   └──────────────┘
```

| Часть | Технологии | Что делает |
|---|---|---|
| Клиент | Unity, C# | 3D-сцена бара, игровой стол, интерфейс, анимации, звук |
| Сервер | C#, Linux | API, игровые комнаты, логика раздач, начисление валюты |
| База данных | MySQL | Аккаунты, баланс фишек, баллы БРС, таблица лидеров |
| 3D-графика | Blender | Модели персонажей-насекомых и интерьера бара |
| Разработка | Git, GitHub | Контроль версий и совместная работа |
